    Wiring - SRAM Socket¶

    Complete every address/data/fixed pin, including CE# U2.22 from U4.12, WE# U2.29 from U4.9, OE# U2.24 from U3.3, CE2 to +5 V, and A16 to GND.

    Complete Z80 CLK/RESET/BUSREQ/WAIT and all control monitor taps. INT/NMI have pulls to +5 V; M1 goes to TP1; HALT/RFSH outputs remain open. Verify pin-1 orientation, power pins, and local bypasses before insertion.

    Automatic Full 64 KiB Test¶

    The z80_stage06_step_loader diagnostic also provides an automatic whole-range test. It requires all eight active packages, checked wiring, and loaded power rails. It uses the existing Z80-assisted loader: Pico injects instructions and supplies clocks; the Z80 alone addresses and writes SRAM. This is destructive and does not load or run CP/M.

    cmake --build build --target z80_stage06_step_loader

    Flash build/src/stage06_sram_dma/z80_stage06_step_loader.uf2, then open the Pico USB serial console at 115200 baud. Apply external 5 V before USB; disconnect USB before external 5 V. Never flash/run with USB alone. Before the serial console connects, the application holds RESET# LOW, CLK LOW, SRAM inhibited and both data paths disabled, without issuing clocks or accessing memory. It waits for the USB CDC console connection (DTR), not merely a plugged-in USB cable. Connecting alone only prints the banner: it still waits for your explicit start command. The startup banner is concise; type f, then press Enter once to run the complete test automatically. No further stepping commands are needed. It can also replace an in-progress manual session, starting a fresh loader.

    The inclusive range is 0000-FFFF, exactly 65,536 byte addresses. An SRAM byte cannot hold 256 or larger, so values wrap:

    1. Low-byte pass: fill the entire range with address & 0xFF (00,01,...,FF,00,01,...), then read the entire range back.
    2. High-byte pass: fill the entire range with address >> 8 (256 zeros, 256 ones, and so on), then read the entire range back.

    Both passes fill all memory before verification. The second pass is important because the low-byte pattern alone cannot distinguish locations 256 bytes apart. Together they check both halves of the address, but they are not a substitute for March tests, analogue margins or timing evidence. After success, SRAM contains the high-byte pattern from the second pass.

    Writing has one short phase banner, not a claimed per-byte success. Verification prints exactly one result line per address, all numbers hexadecimal, using the actual sampled SRAM value:

    address 0000, value 00, expected 00 - SUCCESS
address 0001, value 01, expected 01 - SUCCESS
address 0002, value 02, expected 02 - SUCCESS

    Pass banners distinguish the two patterns. A successful run has 65,536 result lines per pass, 131,072 total, followed by a short success summary. Every completed, failed or aborted run also prints decimal totals:

    STATS: successes=131072 failures=0

    Successes count matching SRAM read-back checks across both passes, not unverified writes: a complete error-free run has 131,072 successes over 65,536 distinct addresses. Failures count a data mismatch, a read/write API error, or loader initialization failure. The test still stops at the first failure, so the failure count is at most one. An operator abort or console disconnection does not count as a failure; its totals are partial. Counters reset on each new f run.

    A mismatch prints the actual value and FAIL, then stops at the first error. An API read/write error explicitly prints value ERROR rather than inventing a read-back value. Loader initialization errors are reported separately and cannot produce a success summary.

    Press x to abort, without Enter. The automatic loop checks input and USB connection between byte operations, not in the middle of a clock pulse. It performs at most one byte write/read per iteration. On abort, failure, completion or console disconnection, both data paths are isolated, reset is asserted and the clock is stopped. While automatic mode is running, other commands are rejected; they do not switch or restart the test. After x, press Enter to clear the input line before f + Enter to restart.

    Automatic mode uses the shared loader's 1 us half-period clocks, not the manual harness's 1 ms half-period clocks. It does not start PWM or execute from SRAM. Actual elapsed time depends on firmware overhead and USB output; these slow-cycle tests do not qualify normal operating speed.

    Automatic test implementation. Host tests verify exact 0000/FFFF bounds, both fill/read passes, all output rows, wrap at 256, detection of 256-byte address aliases, first-error stops, abort boundaries and console-disconnect isolation. Host tests are not physical RAM-test evidence.

    PWM Speed Screening After the Slow Test¶

    After the slow whole-memory test passes, the separate z80_stage06_pwm_memory application can screen actual Z80 execution from SRAM at increasing PWM clock rates. It does not require CP/M, provision flash disks, or start networking. All eight active packages and the complete WAIT/I/O wiring must be fitted. The existing slow diagnostic is unchanged.

    cmake --build build --target z80_stage06_pwm_memory

    Flash build/src/stage06_sram_dma/z80_stage06_pwm_memory.uf2. Keep external 5 V applied before USB and power every fitted IC; USB-only flashing/running is unsupported. Open USB serial at 115200 baud with DTR. Startup holds reset and does not start clocks or memory accesses until f + Enter. Use x without Enter to abort; h + Enter displays help and s + Enter displays status. After aborting, press Enter before starting another run. Disconnecting the console stops the test safely; reconnecting does not resume it.

    The test requests 1-8 MHz in 500 kHz steps, using the existing integer, 50%-duty PWM implementation. It prints requested and nominal actual frequencies; these are not measured frequencies. The 6.5 MHz request duplicates the actual 6 MHz waveform and is skipped after 6 MHz passes. There are 14 distinct actual rates at the configured 144 MHz system clock. Actual rates above 6 MHz are explicitly marked experimental. See the frequency table and timing requirements.

    At each speed:

    1. Load and read back a small test program using slow assisted clocks.
    2. Execute that program from the lower 32 KiB using PWM. Fill the entire upper 32 KiB, then verify it, for each of four patterns: address low byte, address high byte, complemented low byte, complemented high byte.
    3. Reload the program into the upper 32 KiB, with a temporary JP 8000 at reset address zero. Once execution reaches the upper half, repeat the same tests across every lower-half address, including 0000. The program needs no stack and disables maskable interrupts.
    4. Repeat both halves until at least 60 seconds of execution-phase wall time have accumulated and a complete two-half cycle has finished. Assisted loading/verification time is excluded. Execution time includes the brief stepped I/O reports, not exclusively uninterrupted PWM pulses.

    One complete cycle verifies 65,536 addresses against four patterns: 262,144 successful comparisons. Program fetches, branches, reads and writes run at the selected PWM speed. Only short progress/error OUT 06 reports use the existing WAIT trap and slow I/O completion. The main loop must observe a correctly ordered completed-pattern marker within five seconds; a hung CPU cannot become a timed PASS. The longest normal fill/read block is under four million T-states (about four seconds at 1 MHz), leaving a bounded progress margin.

    Output is one RUN line, progress about every ten seconds, and one PASS line per speed, rather than one USB line per byte. For example:

    RUN: requested=1000000Hz actual=1000000Hz minimum=60s
PASS: requested=1000000Hz actual=1000000Hz pwm_ms=... cycles=... successes=... failures=0

    The test stops at the first mismatch, missing/incomplete progress, unexpected I/O, loader error, or trap-counter change. A CPU-detected mismatch includes address, actual byte and expected byte. Final statistics count completed 32 KiB verification blocks only; successful comparisons in an incomplete block are not counted. Abort/disconnection does not count as a failure. Reset is asserted, PWM stopped, SRAM inhibited, and both Pico data paths isolated on completion, failure or abort. A watchdog or power reboot during a run invalidates that run; no new run starts automatically and no unobserved interval can count toward a PASS.

    This is a functional screening result, not frequency qualification. It is not a March/coupling-fault test. The two-half approach also does not establish whole-memory retention across simultaneous patterns in both halves; retain the slow full-range test as complementary alias evidence. Analogue setup/hold and write-pulse margins, clock quality, WAIT handover, and repeated cold starts still need the scope and logic-analyzer qualification procedure.

    Screening implementation. Host tests independently execute the generated Z80 instructions through both halves, check exact fill/read bounds and patterns, inject last-address corruption and 256-byte aliases, and exercise duration, sweep, USB gating, abort, loader failures, protocol errors and timeouts. These tests do not prove physical timing.

    One-Hour 20 MHz Arithmetic and SRAM Soak¶

    For an overnight run, the separate z80_stage06_math_soak_14h_20mhz target uses the identical workload for at least 14 hours (50,400 seconds), stopping at the first failure and finishing only on a complete cycle. The original one-hour target remains available. See the 14-hour build and operating notes.

    See the complete soak-test guide for the instruction inventory, arithmetic/flag assertions, result-port protocol, statistics and run procedure. That page includes the maintained diagnostic README directly.

    z80_stage06_math_soak_20mhz is a separate destructive diagnostic, not a replacement for the full-64-KiB frequency screens. It loads one resident Z80 assembly program and independently calculated reference vectors, then executes continuously without reloading/resetting between cycles.

    cmake --build build/pwm17-20 --target z80_stage06_math_soak_20mhz

    UF2: build/pwm17-20/src/stage06_sram_dma/z80_stage06_math_soak_20mhz.uf2. The existing build directory must first be configured as above. z80asm is required; the build assembles math_soak.asm and embeds its exact bytes. The isolated 20 MHz clock/CPU/trap chain selects 120 MHz Pico clk_sys before USB initialization with Z80 reset asserted, using the same PLL and 50%-duty PWM configuration as the 20 MHz frequency screen. Normal targets remain unchanged.

    The resident memory layout is:

    SRAM addresses Purpose
    0000-0FFF Z80 instructions and two loop-state bytes
    1000-19FF 128 reference records, generated by the Pico using wider C arithmetic
    1A00-1FFF Guarded stack; SP starts at 2000 and grows downward
    2000-FFFF 56 KiB write/read/compare work area

    Each phase performs:

    1. Nested CALL/RET with 16 recursive levels, PUSH/POP register preservation, exact stack-pointer recovery and a lower stack guard.
    2. Sixteen repetitions of 128 operand pairs: 64 boundary-value combinations and 64 deterministic pseudo-random pairs. Each pair checks ADD HL, ADC HL with carry, subtraction via SBC HL with carry clear, SBC HL with borrow, low-16-bit shift/add multiplication, and signed/unsigned ordering. Arithmetic results and documented carry, half-carry, sign, zero, overflow and subtract flags are checked where applicable; undocumented flag bits are masked out. Signed comparison accounts for sign XOR overflow.
    3. A complete fill of 2000-FFFF, followed by complete read/compare. Successive phases use low address, high address, complemented low address and complemented high address bytes. Four phases make a cycle.

    The code, reference and stack regions are not swept as general data. Instruction fetches, table reads and stack accesses exercise them, but this does not claim full-64-KiB destructive coverage; retain the preceding screen. No CP/M or BDOS is installed or required.

    Keep external 5 V applied with every fitted IC powered before flashing or connecting USB. Connect serial with DTR, confirm the 120 MHz supervisor banner, then send f + Enter. A connection alone never starts the test. h gives help, s gives status/statistics, and immediate x aborts. Completion requires at least 3600 seconds of execution-phase elapsed time, excluding initial image loading/verification but including brief I/O report pauses, and a completed four-phase cycle. The program is not reset between phases. There are no added memory wait states.

    How the Z80 Reports Results to the Pico¶

    The Z80 performs the calculations and comparisons; the Pico supervises the run and receives its reports. Results travel through Z80 I/O port 06h, not through a UART, CP/M/BDOS call or an SRAM mailbox. This is an I/O-space address, not SRAM address 0006h. No IN instruction is needed; an unexpected I/O read is treated as a protocol fault.

    After all arithmetic, stack, loop and SRAM checks in a phase succeed, the Z80 executes the equivalent of:

    ld a,040h       ; Phase 0 completed successfully
out (06h),a    ; Send the accumulator byte to the Pico

    The actual program forms the marker from the current phase number. Successive phases send 40h, 41h, 42h, 43h, then repeat in that order. These bytes identify a complete successful phase, not a single arithmetic result or memory comparison.

    Each OUT (06h),A is captured as follows:

    1. The Z80 drives its port address and the accumulator value onto the address and D0-D7 data buses, asserting IORQ# (I/O request) and WR# (write). The # suffix means active LOW.
    2. With Pico IO_RELEASE LOW, the HCT32 equation WAIT# = IORQ# OR IO_RELEASE asserts WAIT#, holding the I/O transaction while the Pico responds.
    3. The buffered IORQ# falling edge interrupts the Pico. The handler stops PWM, allows settling, samples the port through the LVC244 monitor and confirms that this is a write. Only A0/A1/A2/A4 are decoded (address & 0x17), so the port is seen as 06h; unused address bits, including the high byte presented by OUT (n),A, are ignored.
    4. The Pico keeps its upward data driver disabled, enables the downward SN74LVC245AN path and samples the eight data bits at 3.3 V. No raw 5 V Z80 data signal is connected directly to a Pico input.
    5. The soak's receive callback checks the decoded port and byte. An in-order success marker increments the completed-phase counter; an unexpected marker or port flags a protocol error.
    6. The trap raises IO_RELEASE and uses controlled single clock cycles until IORQ# and WR# release. It then isolates both data paths, lowers IO_RELEASE and resumes PWM. The next Z80 instruction follows normally; this reporting transaction does not reset or reload the program.

    Only the short I/O reports use this hardware WAIT/stepped-completion mechanism. SRAM instructions execute at the configured PWM rate without added memory wait states.

    On a failed check, the Z80 instead sends nine bytes, each using a separate OUT (06h),A, then executes HALT:

    Byte position Contents
    0 E1h: failure-packet marker
    1 Check stage
    2 Operand-vector index or diagnostic context
    3, 4 Relevant address, low byte then high byte
    5, 6 Actual 16-bit value, low byte then high byte
    7, 8 Expected 16-bit value, low byte then high byte

    The Pico assembles the packet, prints the mismatch details and fails closed with RESET asserted and PWM stopped. An incomplete packet also fails on timeout. Stages 01-0B identify arithmetic result/flag, multiplication and comparison checks; 0C-10 identify stack checks; 11-12 check vector/repetition loop bounds; 80-83 identify RAM patterns. For arithmetic failures the address identifies the reference record; for RAM failures it identifies the work address. Structural/stack vector indices are diagnostic context, not necessarily a valid operand index.

    Maintained sources: Z80 report instructions, Pico report parser and statistics, and I/O trap and stepped completion.

    The Pico reports progress every ten seconds and fails closed on the first CPU mismatch, malformed/out-of-order report, loader/control error or five-second progress timeout. Disconnect, reboot or abort invalidates the run, not a PASS. A completed PASS holds RESET LOW, stops PWM and isolates both Pico data paths. There is no automatic restart.

    The Pico generates the USB serial PROGRESS and STATS text from the received phase markers and its own elapsed-time measurement. The host logger adds the UTC timestamp and SERIAL prefix shown in the live terminal. Millions of successful checks therefore do not require millions of OUT transactions: the Pico credits the known workload only after receiving each complete-phase success marker. It does not reread every work byte or independently recompute each arithmetic result during the soak.

    STATS reports successful checks and failures, with separate SRAM-byte, arithmetic, stack and loop totals. Each completed phase credits:

    • 57,344 SRAM-byte comparisons;
    • 22,528 arithmetic assertions (2048 complete vectors, 11 assertions each);
    • five stack assertions and 17 loop-bound assertions;
    • 79,894 total successful assertions.

    These are different kinds of assertions, not an instruction count. Partial phases are deliberately not credited. A first failure counts as one; abort/disconnect is not a failure count but is still an incomplete run. Progress statistics alone are not a final PASS. A one-hour pass remains functional soak evidence, not measured analogue timing qualification.

    Host Validation¶

    Host controller tests simulate the exact hour/cycle boundary, counters, serial gating and fault stops. Optional independent instruction execution requires Python 3.10+ and the pinned host-only emulator:

    python3.14 -m venv build/math-soak-emulator
build/math-soak-emulator/bin/python -m pip install \
  -r src/common/tests/requirements-soak.txt
cmake -S src/common/tests -B build/host-control -G Ninja \
  -DSOAK_EMULATOR_PYTHON="$PWD/build/math-soak-emulator/bin/python"

    Commands and first steps¶

    Type one lower-case letter then Enter. CR, LF and CRLF work. Empty Enter does nothing; malformed/multiple-letter lines do not advance. Do not paste command sequences or hold down a key.

    Command Action
    h + Enter Print help, physical probe pin map and current expected behavior; no clocks or ownership changes
    f + Enter Start the automatic full 64 KiB low/high-byte test described above
    b + Enter Begin/restart with RESET# LOW, CLK LOW, SRAM inhibited and data paths isolated; no clocks
    n + Enter Perform exactly one next action: either one complete clock cycle or a labelled no-clock ownership/reset action
    r + Enter Repeat current instructions and observations without changing signals or clocking
    x Abort immediately without Enter: isolate data paths, assert reset and inhibit SRAM output

    After x, press Enter to clear the discarded line before entering b. On any reported mismatch the session stops in reset; n cannot continue from the fault. Record the first error before changing anything.

    1. Read h, then type b + Enter.
    2. Issue n + Enter six times, one reset clock at a time.
    3. The next n checks idle controls and releases reset with CLK stopped LOW; it does not generate a clock.
    4. Issue two further n commands for the existing loader's reset-exit alignment clocks. Physical alignment must still be qualified.
    5. Follow NEXT n for every subsequent action. Setup and injection actions do not clock; T1/T2/T3/T4 actions each clock once and finish LOW.

    Every pulse has 1 ms LOW/HIGH half-periods and the shared clock helper's LOW settling delay. The application never starts PWM. A multimeter sees the held LOW clock between commands; it cannot prove pulse amplitude, edge quality, exact timing, or absence of short glitches.

    Expected instruction and bus sequence¶

    For each target address nn and test byte n, the Z80 executes:

    LD HL,nn       ; 21 low high: set target, using injected opcode/operands
LD (HL),n      ; 36 byte: Z80 drives address/data and writes SRAM
LD A,00        ; 3E 00: clear accumulator without changing SRAM
LD A,(HL)      ; 7E: SRAM supplies the byte; Pico samples through U10

    LD A,00 clears the accumulator, not a persistently driven physical data bus. The zero operand is injected during its own fetch; afterward the upward path is isolated. No extra bus-clear operation or scratch write is performed. The Pico cannot directly observe A; it observes the SRAM data bus during the subsequent read, and the Z80 is expected to latch that byte at read completion.

    Held point Expected address/data ownership and controls
    Injected opcode/operand after T2 Address is the injected instruction PC, not necessarily HL; U9 supplies the printed byte, U10 off, SRAM OE# HIGH
    Z80 write after T2 Address is HL; Z80 supplies the test byte; CE# LOW, WE# LOW, OE# HIGH; U9 off and U10 samples the write data
    SRAM read after T2 Address is HL; SRAM supplies the stored byte; CE# LOW, WE# HIGH, OE# LOW; U9 off and U10 samples the read data
    Opcode T4 Refresh can put a different address on the bus; do not mistake it for a target-address failure

    At the held T2 points, use r to reread instructions without changing bus ownership. The console prints full expected address and byte in hexadecimal and as A15..A0 / D7..D0 bits, and h gives exact SRAM pin numbers. For example, the write/read of address 0002 expects address bits 0000000000000010 and data bits 00000010.

    Use DC volts with the black probe on common circuit GND and insulated tips on the listed pins; never bridge neighboring contacts. Power off before moving clips. HIGH/LOW listings are logic expectations, not measured voltages: compare physical readings against the exact receiver's input limits. Raw Z80 outputs are TTL; a digital HIGH indication does not establish SRAM CMOS margin. Use the scope/analyzer for timing qualification.

    The console compares the U10 data sample with the expected byte during both write T2 and read T2. A write-data match is not yet proof of a committed write; the following T3 finishes it. A read match is counted only after its T3 completes. The next action never hides another clock.

    After all three write/immediate-read pairs, a final console-stepped read-only retention pass reloads each HL address, clears A again and reads the stored byte without rewriting it. This can expose overwrites caused by aliases among these three addresses. A complete sequence has 182 full clock cycles, including six reset and two reset-exit clocks, and six verified read-backs. Completion asserts reset, isolates both data paths and leaves SRAM contents intact.

    What the harness can observe¶

    The Pico checks BUSACK#, IORQ#, RD# and WR# via U7, and only the address bits A0/A1/A2/A4 (mask 17). It checks those address bits at stable fetch, write and read points, not during refresh. It cannot read all sixteen address bits, MREQ#, actual SRAM CE#/OE#/WE#, or actual U9 OE#. Reported enable/inhibit values are Pico-side commands, not measurements of the downstream hardware.

    Host tests decode the injected instructions into a simulated Z80/SRAM and check manual pulse counts, the exact three writes, six accumulator clears, immediate/final read-back, ownership isolation, fault stops and abort at every action. Those tests establish software sequencing, not physical reset-exit alignment, analogue levels, timing or full SRAM qualification.

    Full-Memory Loader Qualification¶

    First capture slow reset exit and injected 21/36/7E sequences with the analyzer, alongside scope measurements of CLK and SRAM controls. Confirm:

    • Six reset clocks and two reset-exit clocks align the first opcode fetch.
    • Opcode fetches have four T-states; operand reads have three.
    • Each slow clock leaves CLK LOW for at least 1 us before returning. Confirm injected data remains valid through RD# release before firmware isolates it.
    • SRAM OE stays HIGH throughout injected bytes.
    • Upward data is disabled before the CPU's memory-write cycle.
    • Readback enables SRAM only after the Pico stops driving.
    • After disabling both translators, allow at least 1 us before changing Pico data pins to outputs; verify U10 is actually high-impedance at that point.
    • SRAM write pulse, address/data setup/hold, and read sample position meet the exact Z80 and SRAM datasheets. Host tests are not this evidence.

    p runs the full 64 KiB address-derived pattern and readback; c the complement; m a full March test. Each command initializes a fresh injected session and finishes with RESET asserted and the clock stopped. Save the first mismatch address/expected/actual; do not advance after an error. Start with the scope-connected current-limited supply and check loaded rail voltage and clock thresholds before long tests.

    Done Command Required result
    Before long tests Loaded rail voltage and clock thresholds checked
    p Full 64 KiB address-derived pattern and readback pass repeatedly
    c Complement pattern and readback pass repeatedly
    m Full March test passes repeatedly

    Pass Gate¶

    • Loader phase verified on real hardware.
    • All three RAM tests pass repeatedly, including addresses 0000/FFFF.
    • No overlapping data drive occurs.
    • Complete the CPU reset, fetch and bus-grant checks, including receiving-pin captures and safe grant/release fault behavior.

static bool report_failure(uint16_t address, uint8_t expected,
                           uint8_t actual) {
  printf("FAIL %04x expected=%02x actual=%02x\n", address, expected, actual);
  z80_isolate_buses();
  return false;
}

bool z80_sram_prepare_loader(void) {
  z80_isolate_buses();
  gpio_put(PIN_BOOT_READ_DISABLE, 1);
  gpio_put(PIN_BUSREQ_N, 1);
  z80_reset_with_clock_cycles(6, 1);
  gpio_put(PIN_RESET_N, 1);
  z80_clock_one_cycle(1);
  z80_clock_one_cycle(1);
  return true;
}

static void pulse_clock(unsigned cycles) {
  for (unsigned cycle = 0; cycle < cycles; ++cycle)
    z80_clock_one_cycle(1);
}

static void inject_read(uint8_t value, bool opcode) {
  pulse_clock(1);
  gpio_put(PIN_BOOT_READ_DISABLE, 1);
  busy_wait_us_32(1);
  z80_data_bus_drive(value);
  pulse_clock(2);
  z80_data_bus_isolate();
  if (opcode)
    pulse_clock(1);
}

static void load_hl(uint16_t address) {
  inject_read(0x21, true);
  inject_read((uint8_t)address, false);
  inject_read((uint8_t)(address >> 8), false);
}

bool z80_sram_write_byte(uint16_t address, uint8_t value) {
  load_hl(address);
  inject_read(0x36, true);
  inject_read(value, false);
  pulse_clock(3);
  return true;
}

bool z80_sram_read_byte(uint16_t address, uint8_t *value) {
  if (value == NULL)
    return false;

  load_hl(address);
  inject_read(0x7E, true);
  z80_data_bus_prepare_input();
  gpio_put(PIN_BOOT_READ_DISABLE, 0);
  pulse_clock(2);
  busy_wait_us_32(1);
  *value = z80_data_bus_sample();
  pulse_clock(1);
  z80_data_bus_isolate();
  gpio_put(PIN_BOOT_READ_DISABLE, 1);
  return true;
}

bool z80_sram_load(uint16_t address, const uint8_t *data, uint32_t length) {
  if (data == NULL || length > 65536u - address)
    return false;
  for (uint32_t index = 0; index < length; ++index) {
    if (!z80_sram_write_byte((uint16_t)(address + index), data[index]))
      return false;
  }
  z80_isolate_buses();
  return true;
}

bool z80_sram_verify(uint16_t address, const uint8_t *data, uint32_t length) {
  if (data == NULL || length > 65536u - address)
    return false;
  for (uint32_t index = 0; index < length; ++index) {
    uint8_t actual = 0;
    if (!z80_sram_read_byte((uint16_t)(address + index), &actual) ||
        actual != data[index])
      return report_failure((uint16_t)(address + index), data[index], actual);
  }
  z80_isolate_buses();
  return true;
}

bool z80_sram_pattern_test(bool complement) {
  for (uint32_t address = 0; address < 65536u; ++address) {
    uint8_t expected = (uint8_t)address ^ (uint8_t)(address >> 8);
    if (complement)
      expected = (uint8_t)~expected;
    if (!z80_sram_write_byte((uint16_t)address, expected))
      return false;
  }
  for (uint32_t address = 0; address < 65536u; ++address) {
    uint8_t expected = (uint8_t)address ^ (uint8_t)(address >> 8);
    uint8_t actual = 0;
    if (complement)
      expected = (uint8_t)~expected;
    if (!z80_sram_read_byte((uint16_t)address, &actual) || actual != expected)
      return report_failure((uint16_t)address, expected, actual);
  }
  z80_isolate_buses();
  return true;
}

static bool march_read_write(uint16_t address, uint8_t expected,
                             uint8_t replacement) {
  uint8_t actual = 0;
  if (!z80_sram_read_byte(address, &actual) || actual != expected)
    return report_failure(address, expected, actual);
  return z80_sram_write_byte(address, replacement);
}

bool z80_sram_march_test(void) {
  for (uint32_t address = 0; address < 65536u; ++address) {
    if (!z80_sram_write_byte((uint16_t)address, 0x00))
      return false;
  }
  for (uint32_t address = 0; address < 65536u; ++address) {
    if (!march_read_write((uint16_t)address, 0x00, 0xFF))
      return false;
  }
  for (uint32_t address = 0; address < 65536u; ++address) {
    if (!march_read_write((uint16_t)address, 0xFF, 0x00))
      return false;
  }
  for (uint32_t address = 65536u; address-- > 0;) {
    if (!march_read_write((uint16_t)address, 0x00, 0xFF))
      return false;
  }
  for (uint32_t address = 65536u; address-- > 0;) {

      return false;
  }

      return report_failure((uint16_t)address, 0x00, actual);
  }

  return true;

    printf("NEXT n: check idle controls, then release RESET# while CLK LOW;\n"
           "NO clock. Six reset clocks already completed.\n");
  } else if (phase == RESET_EXIT) {
    printf("NEXT n: reset-exit alignment clock %u/2; SRAM inhibited.\n",
           exit_clocks + 1);
  } else {
    const transfer_t *transfer = &TRANSFERS[transfer_index];
    printf("%s pair %u/3: [%04x]=%02x; injected PC=%04x\n"
           "TRANSFER: %s\nEXPECTED: %s\n",
           retention ? "FINAL RETENTION" : "WRITE / IMMEDIATE READ",
           test_index + 1, TEST_BYTES[test_index].address,
           TEST_BYTES[test_index].value, injected_pc,
           transfer->description, transfer->expected);
    if (injected())
      printf("Injected byte=%02x; fetch address=%04x, NOT necessarily HL.\n",
             transfer_byte(), injected_pc);
    switch (phase) {
    case SETUP:
      printf("NEXT n: NO clock; %s.\n",
             injected() ? "inhibit SRAM and isolate both data paths" :
             transfer->kind == CPU_WRITE ?
                 "inhibit SRAM output; configure U10 input to observe Z80 write" :
                 "isolate upward drive; configure U10 input; enable SRAM reads");
      break;
    case T1:
      printf("NEXT n: clock T1; target/fetch address and bus controls assert.\n");
      break;
    case DRIVE:
      printf("NEXT n: NO clock; check fetch controls/address, then inject %02x\n"
             "through U9. SRAM output MUST stay inhibited; U10 off.\n",
             transfer_byte());
      break;
    case T2:
      printf("NEXT n: clock T2; expected RD#=%u WR#=%u, address=%04x.\n",
             (unsigned)(transfer->kind == CPU_WRITE),
             (unsigned)(transfer->kind != CPU_WRITE),
             injected() ? injected_pc : TEST_BYTES[test_index].address);
      if (!injected())
        printf("Sample physical data bus via U10; expected=%02x.\n",
               transfer_byte());
      break;
    case T3:
      printf("HELD after T2: %s; expected bus=%02x.\n"
             "NEXT n: clock T3 to finish this transfer, then isolate data.\n",
             injected() ? "U9 supplies injected byte (command, not read-back)" :
             transfer->kind == CPU_WRITE ? "Z80 drives, SRAM write active" :
                                          "SRAM drives, Z80 read active",
             transfer_byte());
      printf("Probe SRAM A0-A15 for %04x and D0-D7 for %02x now;\n"
             "see h for physical pins. 1=HIGH, 0=LOW (logic expectations).\n",
             injected() ? injected_pc : TEST_BYTES[test_index].address,
             transfer_byte());
      print_bits("EXPECTED A15..A0 = ",
                 injected() ? injected_pc : TEST_BYTES[test_index].address, 16);
      print_bits("EXPECTED D7..D0 = ", transfer_byte(), 8);
      break;
    case T4:
      printf("NEXT n: opcode T4 refresh clock; U9/U10 off, SRAM inhibited.\n"
             "Address pins may show refresh address, NOT the test target.\n");
      break;
    default:
      break;
    }
    printf("RD#/WR# are active LOW. Full write/read address and SRAM pins\n"
           "must be checked externally; U7 sees only A0/A1/A2/A4.\n");
  }
  printf("n + Enter advances; r repeats; x stops immediately.\n");
}

static void begin_test(void) {
  safe_stop();
  reset_clocks = exit_clocks = total_clocks = 0;
  test_index = transfer_index = verified_reads = 0;
  injected_pc = 0;
  retention = false;
  phase = RESET_CLOCK;
  printf("\nARMED: existing SRAM will be overwritten ONLY at 0000/0001/0002.\n");
  print_status();
}

static void clock_once(void) {
  z80_clock_one_cycle(STEP_HALF_PERIOD_US);
  ++total_clocks;
}

static void finish_transfer(void) {
  if (injected())
    ++injected_pc;
  if (transfer_index == 7)
    printf("EXPECTED CPU A=00 after LD A,00; register not directly measured.\n");
  ++transfer_index;
  if (retention && transfer_index == 3)
    transfer_index = 6;
  if (transfer_index == TRANSFER_COUNT) {
    transfer_index = 0;
    ++test_index;
    if (test_index == TEST_COUNT) {
      test_index = 0;
      if (retention) {
        safe_stop();
        phase = COMPLETE;
        return;
      }
      retention = true;
      printf("\nAll writes done. FINAL RETENTION: reread every location;\n"
             "do NOT rewrite memory. This can expose aliases among these bytes.\n");
    }
  }
  phase = SETUP;
}

static void next_action(void) {
  if (phase == STOPPED || phase == COMPLETE) {
    printf("No advance: use b + Enter to begin/restart.\n");
    return;
  }
  switch (phase) {
  case RESET_CLOCK:
    clock_once();
    if (++reset_clocks == 6)
      phase = RELEASE_RESET;
    break;
  case RELEASE_RESET:
    if (!check_controls(true, true, false))
      return;
    gpio_put(PIN_RESET_N, 1);
    busy_wait_us_32(1);
    phase = RESET_EXIT;
    break;
  case RESET_EXIT:
    clock_once();
    if (++exit_clocks == 2)
      phase = SETUP;
    break;
  case SETUP:
    z80_data_bus_isolate();
    gpio_put(PIN_BOOT_READ_DISABLE, 1);
    if (!injected()) {
      z80_data_bus_prepare_input();
      if (TRANSFERS[transfer_index].kind == SRAM_READ)
        gpio_put(PIN_BOOT_READ_DISABLE, 0);
    }
    busy_wait_us_32(1);
    phase = T1;
    break;
  case T1:
    clock_once();
    phase = injected() ? DRIVE : T2;
    break;
  case DRIVE:
    if (!check_controls(false, true, true))
      return;
    z80_data_bus_drive(transfer_byte());
    phase = T2;
    break;
  case T2: {
    clock_once();
    bool writing = TRANSFERS[transfer_index].kind == CPU_WRITE;
    if (!check_controls(writing, !writing, true))
      return;
    if (!injected()) {
      uint8_t actual = z80_data_bus_sample();
      printf("%s BUS SAMPLE: address=%04x expected=%02x actual=%02x\n",
             writing ? "Z80 WRITE" : "SRAM READ",
             TEST_BYTES[test_index].address, transfer_byte(), actual);
      if (actual != transfer_byte()) {
        fail(writing ? "Z80 write data mismatch" : "SRAM read-back mismatch");
        return;
      }
      printf("MATCH: %s; %s\n",
             writing ? "CPU-driven write data" : "SRAM-driven read data",
             writing ? "write not complete until T3" :
                       "CPU read not complete until T3");
    }
    phase = T3;
    break;
  }
  case T3:
    clock_once();
    if (!check_controls(true, true, false))
      return;
    z80_data_bus_isolate();
    gpio_put(PIN_BOOT_READ_DISABLE, 1);
    if (TRANSFERS[transfer_index].kind == SRAM_READ)
      ++verified_reads;
    if (TRANSFERS[transfer_index].kind == OPCODE)
      phase = T4;
    else
      finish_transfer();
    break;
  case T4:
    clock_once();
    if (!check_controls(true, true, false))
      return;
    finish_transfer();
    break;
  default:
    fail("invalid step state");
    return;
  }
  print_status();
}

static void run_command(int command) {
  if (z80_full_memory_test_active()) {
    printf("BUSY: automatic full-memory test; x aborts between bytes.\n");
    return;
  }
  if (command == 'f') {
    safe_stop();
    total_clocks = verified_reads = 0;
    z80_full_memory_test_start();
  } else if (command == 'b')
    begin_test();
  else if (command == 'n')
    next_action();
  else if (command == 'r')
    print_status();
  else if (command == 'h') {
    print_help();
    print_status();
  } else
    printf("ERROR: unknown command; outputs unchanged. Use h + Enter.\n");
}

static void handle_character(int character) {
  if (character == 'x') {
    safe_stop();
    pending_command = 0;
    invalid_line = true;
    if (z80_full_memory_test_active())
      z80_full_memory_test_abort("operator");
    else
      printf("\nABORTED: RESET# LOW, CLK LOW, inhibit HIGH, data paths off.\n");
  } else if (character == '\r' || character == '\n') {
    if (invalid_line)
      printf("Line discarded. Use one command letter then Enter.\n");
    else if (pending_command)
      run_command(pending_command);
    pending_command = 0;
    invalid_line = false;
  } else if (pending_command || invalid_line) {
    invalid_line = true;
  } else {
    pending_command = character;
  }
}

int main(void) {
  z80_safe_startup();
  safe_stop();
  stdio_init_all();
  while (true) {
    while (!stdio_usb_connected())
      tight_loop_contents();
    pending_command = 0;
    invalid_line = false;
    printf("\nZ80 SRAM diagnostic: RESET# LOW; all ICs required.\n"
           "Console connected. Waiting for a command; no test has started.\n"
           "f + Enter = automatic full 64 KiB low/high-byte test; x = abort\n"
           "b + Enter = three-byte single-step test; h + Enter = full help\n"
           "Destructive test. External 5 V before USB; no USB-only power.\n");
    while (stdio_usb_connected()) {
      int character = getchar_timeout_us(0);
      if (character >= 0)
        handle_character(character);
      if (z80_full_memory_test_active()) {
        if (!stdio_usb_connected())
          break;
        z80_full_memory_test_tick();
      }
      tight_loop_contents();
    }
    safe_stop();
    z80_full_memory_test_abort("console disconnected");
  }
}

#include <stdint.h>
#include <stdio.h>

#include "z80sbc/cpu.h"
#include "z80sbc/sram.h"

enum { MEMORY_SIZE = 65536 };

static bool active;
static bool verifying;
static unsigned pattern;
static uint32_t address;
static unsigned successful_checks;
static unsigned failed_checks;

static uint8_t expected_byte(void) {
  return pattern == 0 ? (uint8_t)address : (uint8_t)(address >> 8);
}

static void stop(void) {
  z80_cpu_fail_closed();
  active = false;
}

static void print_stats(void) {
  printf("STATS: successes=%u failures=%u\n", successful_checks, failed_checks);
}

static void start_pattern(void) {
  address = 0;
  verifying = false;
  if (!z80_cpu_prepare_loader()) {
    ++failed_checks;
    stop();
    printf("FAIL: loader initialization for pass %u/2\n", pattern + 1);
    print_stats();
    return;
  }
  active = true;
  printf("pass %u/2: writing 0000-ffff, pattern=address %s byte; x aborts\n",
         pattern + 1, pattern == 0 ? "low" : "high");
}

void z80_full_memory_test_start(void) {
  stop();
  pattern = 0;
  successful_checks = failed_checks = 0;
  start_pattern();
}

bool z80_full_memory_test_active(void) {
  return active;
}

void z80_full_memory_test_abort(const char *reason) {
  if (!active)
    return;
  stop();
  printf("ABORTED: %s; RESET# LOW, SRAM inhibited, data paths off\n", reason);
  print_stats();
}

void z80_full_memory_test_tick(void) {
  if (!active)
    return;

  uint8_t expected = expected_byte();
  if (!verifying) {
    if (!z80_sram_write_byte((uint16_t)address, expected)) {
      ++failed_checks;
      stop();
      printf("address %04x, value ERROR, expected %02x - FAIL (write)\n",
             (unsigned)address, expected);
      print_stats();
      return;
    }
  } else {
    uint8_t actual;
    if (!z80_sram_read_byte((uint16_t)address, &actual)) {
      ++failed_checks;
      stop();
      printf("address %04x, value ERROR, expected %02x - FAIL (read)\n",
             (unsigned)address, expected);
      print_stats();
      return;
    }
    bool matches = actual == expected;
    if (matches)
      ++successful_checks;
    else {
      ++failed_checks;
      stop();
    }
    printf("address %04x, value %02x, expected %02x - %s\n",
           (unsigned)address, actual, expected, matches ? "SUCCESS" : "FAIL");
    if (!matches) {
      print_stats();
      return;
    }
  }

  if (++address != MEMORY_SIZE)
    return;
  if (!verifying) {
    address = 0;
    verifying = true;
    printf("pass %u/2: reading 0000-ffff\n", pattern + 1);
  } else if (pattern == 0) {
    pattern = 1;
    start_pattern();
  } else {
    stop();
    printf("SUCCESS: 65536 addresses verified in each of 2 passes; RESET# LOW\n");
    print_stats();
  }
}
